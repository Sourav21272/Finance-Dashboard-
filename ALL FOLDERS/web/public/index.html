Troubleshooting & how to run the server

If PowerShell shows: "npm.ps1 cannot be loaded because running scripts is disabled", use one of the options below.

  1. Quick & safe — use Command Prompt (recommended)
    Open Start → type cmd → open Command Prompt, then run: 
    npm init -y
npm install express socket.io
node server.js
  2. Allow npm scripts for current user (PowerShell)
    In an elevated PowerShell (Run as Administrator) or regular PowerShell for current user, run: 
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
# then close/open PowerShell and run:
npm init -y
npm install express socket.io
node server.js
    Note: RemoteSigned is a common choice; it allows locally created scripts to run.
  3. Run npm with an execution-policy bypass (one-time)
    From PowerShell you can run npm with a bypass (no permanent policy change): 
    powershell -ExecutionPolicy Bypass -Command "npm init -y"
  4. Call the npm executable directly
    Try: 
    npm.cmd init -y
    (sometimes avoids the .ps1 policy restriction)
  5. Alternative shells
    You can also use Git Bash, WSL, or Cmder to run npm without changing PowerShell policies.

After installing dependencies, run your server from the project folder:

node server.js
# then open http://localhost:3000 in your browser

If you want a quick static preview of the UI without the server (no real-time chat), just open this file directly in the browser — the UI will display but real-time messaging requires the Node server + socket.io.

More info: https://learn.microsoft.com/powershell/module/microsoft.powershell.security/set-executionpolicy
